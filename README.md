# 모아픽 · Moapic

**스크린샷과 저장 이미지를, 사진 속 내용으로 다시 찾는 안드로이드 사진첩.**

현재 버전 **0.3.0 · 설치 테스트용**, Android 10 이상.

## 사용하는 방법

1. 사진 접근을 허용하면 스크린샷과 Download 폴더 이미지를 모아 보여줍니다.
2. 검색을 자동 준비합니다. 숫자 **12900**, 영문 **ABC**, 한글 **예약**처럼 입력하면 사진 속 내용으로 찾습니다.
   처음에는 시간이 필요합니다. 프로세스가 종료되면 다음 실행 시 저장된 결과를 이어 사용합니다.
3. 사진을 누르면 원본을 크게 열고, 두 손가락/두 번 누르기로 확대합니다. 긴 사진은 위아래로 끌어 봅니다.
4. 즐겨찾기·태그·공유를 사용하거나 길게 눌러 여러 장을 정리합니다.
5. 사진 삭제는 확인을 거쳐 휴대폰 원본까지 영구 삭제합니다. 복원 기능은 없습니다.

## 캡처 모드

**화면 전체**: 7초 카운트다운 뒤 화면 한 장을 PNG로 저장합니다.

**선택 영역**: 7초 뒤 찍힌 화면에서 네모의 모서리를 조절해 필요한 부분만 원본 해상도로 저장합니다.

**긴 페이지(시험 기능)**: 첫 화면에서 스크롤되는 부분만 선택합니다. 직접 반 화면씩 아래로 내리고
**화면 추가**를 반복한 뒤 **완료·저장**을 누르면 한 장으로 이어 저장합니다.
고정된 메뉴와 아래 버튼은 처음 선택에서 제외하세요. 겹치는 부분이 없거나 모호하면 재시도를 안내합니다.
자동 스크롤은 하지 않습니다. 현재 40화면/총 6천만 픽셀/5분 세션 한도이며 회전은 피하세요.

선택 영역·긴 캡처에는 ‘다른 앱 위에 표시’ 권한이 필요합니다. 일반 캡처는 권한 없이 알림 카운트다운을 쓸 수 있습니다.
시스템 화면 공유 동의는 매번 필요합니다. 보안 화면은 캡처가 제한될 수 있습니다.
캡처 결과는 `Pictures/Screenshots/Moapic/`에 저장합니다. 다른 앱으로 공유할 수도 있습니다.

## 쉽게 쓰는 캡처 버튼

설정의 **위에서 내려 쓰는 캡처 버튼 만들기**를 누릅니다.
화면 맨 위를 두 번 내려 **모아픽 캡처**를 누르면 앱을 열지 않고 한 장을 캡처합니다.
버튼이 없으면 연필/편집에서 ‘모아픽 캡처’를 위쪽 버튼들 사이로 옮기세요.
타일·홈 바로가기는 시스템 동의 창이 닫힌 뒤 약 1.5초 후 캡처합니다.

## 개인정보와 저장

로그인·광고·서버·인터넷 권한이 없습니다. 한국어·영문 OCR 모델도 앱에 포함합니다.
자동으로 모은 원본은 복사하지 않습니다. 직접 추가한 파일은 `Pictures/Moapic/Imports/`에 복사합니다.
다운로드 여부는 폴더 경로로 추정하며 메신저 폴더는 설정에서 추가할 수 있습니다.
태그·즐겨찾기·검색 색인은 앱 전용 저장 공간에 보관하며 자동 백업을 비활성화했습니다.
앱 삭제 시 이 정리 정보는 삭제되고 공용 사진 폴더의 파일은 유지됩니다.
긴 캡처 중간 파일은 앱 임시 폴더에 보관하고 종료 시 정리합니다.

## 빌드

Java 17 / Gradle 8.13 / AGP 8.13.2 / Android SDK 36 / minSdk 29.
Android Studio에서 이 폴더를 열거나 아래 명령으로 빌드합니다.

```powershell
.\gradlew.bat -PdeviceApk=true testDebugUnitTest lintPreview assemblePreview
```

APK는 `app/build/outputs/apk/preview/`에 생성됩니다.
`preview`는 R8 최적화·기기별 라이브러리 분리·압축을 적용하고 테스트 키로 서명합니다.
이 작업 환경의 도구는 상위 `.tools/`에 있으며 `build-local.ps1`을 사용할 수 있습니다.

## 검증과 Google Play

단위 테스트 13개, 컴파일, 정적 검사와 APK 서명을 확인합니다.
실제 휴대폰의 제스처·원본 확대·OCR·영역 선택·스크롤 연결·화면 배치는 별도 검증이 필요합니다.
검색 정확도와 스크롤 연결은 이미지 내용에 따라 달라집니다. 원본보다 없던 디테일을 만들어 내지는 않습니다.

[검증 범위](docs/VALIDATION.md) · [출시 방향](docs/PLAY-PLAN.md) · [출시 준비](docs/RELEASE.md)

Google Play에 아직 제출하지 않았습니다. 출시 키·운영 연락처·정책 신고·기기 검증이 남아 있습니다.
이 채팅에서 완료한 업데이트는 확인 후 이 저장소와 버전별 배포 페이지에 반영합니다.
