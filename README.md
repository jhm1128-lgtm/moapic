# 모아픽 · Moapic

스크린샷과 다운로드 이미지만 모아서 다시 찾는 안드로이드 사진첩입니다.
현재 버전: **0.2.0 / 설치 테스트용**. Android 10 이상 지원.

## 바로 설치하기

- [대부분의 안드로이드 휴대폰용 APK · ARM64 · 약 8.1 MB](https://github.com/jhm1128-lgtm/moapic/raw/refs/heads/main/downloads/moapic-0.2.0-arm64.apk)
- [32비트 ARM 휴대폰용 APK · 약 7.2 MB](https://github.com/jhm1128-lgtm/moapic/raw/refs/heads/main/downloads/moapic-0.2.0-arm32.apk)
- [설치·사용 안내](downloads/INSTALL.md)

기존 0.1.0과 같은 테스트 키로 서명했습니다. 기존 앱 위에 업데이트 설치할 수 있습니다.
공개 스토어 출시용 서명은 아직 구성하지 않았습니다. 실제 기기 기능·화면 검증은 남아 있습니다.
이 채팅에서 완성한 업데이트는 확인 후 이 저장소에 반영합니다.

## 구현한 기능

- MediaStore에서 스크린샷·Download 폴더 이미지를 날짜순으로 표시합니다.
- 전체 / 스크린샷 / 다운로드 / 즐겨찾기 필터를 제공합니다.
- 자동 모으기를 각각 켜고 끄거나 추가 폴더를 선택할 수 있습니다.
- 사진 접근을 허용하지 않아도 직접 추가한 이미지와 앱에서 캡처한 이미지는 사용할 수 있습니다.
- Android 14 이상에서는 전체 접근과 선택한 사진 접근을 구분해 안내합니다.
- 즐겨찾기, 태그, 파일명·태그 검색을 지원합니다. 길게 누르면 여러 장을 정리할 수 있습니다.
- ‘글자 읽기’를 누르면 내장된 ML Kit 한국어·라틴 문자 모델로 기기 내에서 색인을 만들고 검색합니다.
- 다른 앱의 공유 메뉴 → 모아픽, 또는 이미지 추가로 파일을 복사해서 가져옵니다.
- 원본 이미지를 다른 앱에 공유할 수 있습니다.
- 시스템 화면 공유 동의 → 7초 뒤 스크린샷 한 장 저장 → 화면 공유 종료.
- 캡처 진행 알림의 ‘취소’ 또는 시스템 화면 공유 중지로 중단할 수 있습니다.
- 사진 상세 화면이나 길게 눌러 여러 장 선택 후 원본을 삭제할 수 있습니다. 앱 확인과 OS 확인을 거칩니다.
  Android 10은 파일마다 시스템 확인을 받으며, Android 11 이상에서는 여러 장을 한 번에 확인합니다.
- 알림창 빠른 설정의 ‘모아픽 캡처’ 타일로 갤러리를 열지 않고 캡처할 수 있습니다.
- 앱 내 ‘알림창에 스크린샷 버튼 추가’를 누르면 Android 13 이상에서 시스템 추가 창이 열립니다.
  이전 버전에서는 빠른 설정의 편집 화면에서 직접 추가합니다.
- 타이틀 사진과 ‘이제 간편하게 모아보아요’ 문구를 약 2.2초 표시한 뒤 메인 화면으로 전환합니다.
- 설정은 톱니바퀴, 주요 동작은 전용 아이콘, 글자 읽기는 ABC/가나다 아이콘으로 표시합니다.
- 카운트다운 7→1을 캡처 알림에 표시하고, ‘다른 앱 위에 표시’를 허용하면 다른 앱에서도 숫자를 띄웁니다.
  오버레이를 제거한 뒤 새 화면 버퍼로 캡처하여 숫자가 저장되지 않도록 처리합니다.
- 앱 설정에서 정리 정보만 초기화할 수 있습니다.

## 용량 개선

이전 설치 파일은 디버그 빌드와 ARM/x86 4종 라이브러리를 모두 담았습니다.
0.2.0 설치 파일은 R8 최적화와 네이티브 압축을 적용하고, ARM64와 ARM32를 분리합니다.
한국어·영문 글자 읽기와 오프라인 동작은 유지합니다. 추가 모델 다운로드가 필요하지 않습니다.
기기에 맞는 APK 한 개만 설치하세요. 대부분의 최신 안드로이드 휴대폰은 ARM64입니다.
파일 크기와 검증 결과는 `docs/VALIDATION.md`에 기록합니다.

## 사진 저장 원칙

자동으로 모은 사진은 원본을 복사하지 않고 참조합니다. ‘이미지 추가’나 공유로 가져온 사진은
`Pictures/Moapic/Imports/`에 복사합니다. 새로 찍은 스크린샷은
`Pictures/Screenshots/Moapic/`에 PNG로 저장합니다.

다운로드 여부는 운영체제가 보장하는 속성이 아니라 폴더 경로를 이용한 추정입니다.
카카오톡·브라우저 등 다른 폴더에 저장된 이미지는 설정에서 해당 폴더를 추가해 주세요.
직접 추가 폴더의 이미지는 ‘전체’에 표시됩니다. 촬영 사진도 폴더를 직접 선택하면 포함됩니다.

앱은 인터넷 권한을 요청하지 않습니다. 계정·광고·클라우드·분석 서버가 없습니다.
태그, 즐겨찾기, 인식한 글자는 앱 전용 SQLite에 저장하며 자동 백업을 비활성화했습니다.
앱 삭제 시 정리 정보는 삭제됩니다. 공용 사진 폴더의 원본과 가져온 파일은 유지됩니다.

## 사용 순서

1. APK를 휴대폰으로 옮겨 설치하고 모아픽을 엽니다.
2. 자동 모으기 안내를 눌러 사진 접근을 허용합니다. 전체 접근을 허용해야 새 사진도 자동으로 검색됩니다.
3. 스크린샷과 다운로드 이미지가 보이는지 확인합니다. 빠진 저장 폴더는 설정에서 추가합니다.
4. ‘글자 읽기’를 눌러 검색 색인을 만듭니다. 이 작업은 앱 프로세스가 종료되면 중단될 수 있습니다.
   다시 누르면 이미 처리한 파일은 건너뛰고, 실패했거나 변경된 파일을 재시도합니다.
5. ‘화면 캡처’ → 안내 → 시스템 허용을 진행합니다. 다른 앱 화면을 찍으려면 시스템 창에서
   ‘전체 화면’을 선택한 뒤 7초 안에 원하는 화면으로 이동합니다.
6. 카운트다운을 다른 앱 위에서 보고 싶으면 최초 안내 또는 설정에서 표시 권한을 허용합니다.
   알림 권한과 표시 권한을 모두 거부하면 숫자를 볼 수 없습니다. 캡처 동의는 매번 시스템에서 받습니다.
7. 빠른 설정 타일/홈 바로가기는 화면 공유 동의 뒤 약 1.5초 후 캡처합니다. 알림창이 닫힐 시간을 둡니다.
8. 사진을 지우려면 상세 화면의 ‘사진 삭제’ 또는 여러 장 선택 뒤 휴지통 아이콘을 누릅니다.
   삭제는 원본 파일의 영구 삭제이며 휴지통 보관 기능은 없습니다.

금융·DRM·기타 보안 화면은 검게 저장되거나 캡처가 제한될 수 있습니다.
잠금, 동의 취소, 시스템 종료 요청 시 세션을 종료합니다. 녹화·오디오 수집은 하지 않습니다.

## 개발과 빌드

- Java 17, Gradle 8.13, Android Gradle Plugin 8.13.2
- compileSdk / targetSdk 36, minSdk 29
- Android SDK Platform 36 및 Build Tools 35.0.0
- ML Kit 번들 모델 16.0.1 (한국어, 라틴 문자)

Android Studio에서 이 폴더를 열어 실행할 수 있습니다. SDK 위치는 로컬 환경에 맞게 설정하세요.
이 작업 폴더에서는 상위 `.tools/`에 JDK·Gradle·Android SDK를 설치했습니다.

```powershell
.\build-local.ps1
```

표준 Gradle 환경에서는:

```powershell
.\gradlew.bat -PdeviceApk=true testDebugUnitTest lintPreview assemblePreview
```

결과 APK: `app/build/outputs/apk/preview/app-arm64-v8a-preview.apk` 및 ARM32 파일.
`preview`는 출시 빌드처럼 최적화하되 기존 테스트 앱에 덮어 설치할 수 있도록 디버그 키로 서명합니다.
Google Play 공개 출시용 서명은 구성하지 않았습니다.

## 검증 범위와 남은 작업

파일 분류 규칙의 단위 테스트, Android Lint, APK 빌드로 정적 검증합니다.
실제 기기에서 사진 권한·부분 접근·화면 전환·공유·한국어 OCR·회전·캡처 취소 검증은 별도로 필요합니다.
에뮬레이터/기기 검증 여부는 `docs/VALIDATION.md`를 확인하세요.

현재는 첫 기능 검증용입니다. 백그라운드 지속 색인, 휴지통, 자동 카테고리 분류,
중복 탐지, 클라우드 백업은 포함하지 않습니다. 대용량 사진첩에서는 메모리 목록 대신
페이징과 색인 전용 저장 계층으로 확장이 필요합니다.

Google Play 공개 출시는 `docs/RELEASE.md`의 남은 절차를 마친 뒤 진행하세요.
현재 applicationId `app.moapic.gallery`와 앱 이름은 임시 값입니다.
