# 모아픽 0.2.0 · 이제 간편하게 모아보아요

## 설치

- 대부분의 최신 안드로이드 휴대폰: `moapic-0.2.0-arm64.apk`
- 32비트 ARM 휴대폰: `moapic-0.2.0-arm32.apk`
- 둘 중 기기에 맞는 한 개만 설치합니다. Android 10 이상이 필요합니다.
- 기존 모아픽을 삭제하지 않고 덮어 설치할 수 있도록 동일한 테스트 키로 서명했습니다.
  같은 서명의 0.1.0에서 업데이트하면 앱 전용 태그·즐겨찾기를 유지할 수 있습니다.

## 추가한 기능

- 사진 상세 화면에서 ‘사진 삭제’, 또는 길게 눌러 여러 장 선택 후 휴지통을 누릅니다.
  안내와 시스템 확인을 거쳐 원본도 영구 삭제합니다. 앱에서 되돌릴 수 없습니다.
- 메인 화면의 ‘알림창에 스크린샷 버튼 추가’를 누릅니다. 추가 후 알림창을 두 번 내려
  ‘모아픽 캡처’를 누르면 갤러리를 열지 않고 화면 공유 동의 후 캡처합니다.
  Android 10~12는 빠른 설정의 편집 버튼에서 타일을 직접 추가합니다.
- 메인 ‘화면 캡처’는 7초 카운트다운을 표시합니다. ‘다른 앱 위에 표시’를 허용하면
  다른 앱 화면에서도 숫자가 보입니다. 거부하면 캡처 알림에 숫자를 표시합니다.
  알림 권한도 거부한 경우에는 숫자를 볼 수 없으므로 표시 권한 또는 알림을 허용해 주세요.
- 숫자를 지운 뒤 새 화면 버퍼로 캡처하도록 처리했습니다. 캡처 알림의 취소도 사용할 수 있습니다.
- 빠른 설정 타일과 홈 바로가기는 동의 창이 닫힌 뒤 약 1.5초 후 한 장을 저장합니다.
- 시작 사진과 ‘이제 간편하게 모아보아요’ 문구가 잠시 보이고 메인으로 전환됩니다.
- 설정은 톱니바퀴, 캡처·이미지 추가·글자 읽기는 전용 아이콘으로 변경했습니다.

## 용량과 개인정보

기기별 설치 파일 분리·압축·최적화로 ARM64 파일을 약 8.1 MB로 줄였습니다.
한국어·영문 글자 검색은 그대로 동작하도록 구성했고, 모델 추가 다운로드는 필요 없습니다.
새 시작 사진은 약 41 KB입니다. 계정·광고·분석 서버나 인터넷 권한은 없습니다.

## 검증 범위

컴파일, 분류·카운트다운 테스트 6개, 안드로이드 정적 검사와 APK 서명을 확인했습니다.
실제 휴대폰 동작과 화면 배치는 아직 검증하지 않았습니다. Google Play에 공개된 버전이 아닙니다.
