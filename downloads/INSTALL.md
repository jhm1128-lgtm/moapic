# 모아픽 0.3.0 · 사진 속 내용으로 찾아보아요

## 다운로드

이 페이지를 휴대폰 Chrome에서 열고 아래 **Assets → moapic-0.3.0-arm64.apk**를 누르세요.
32비트 ARM 휴대폰은 arm32 APK를 선택합니다. 기존 테스트 앱 위에 덮어 설치할 수 있습니다.

## 달라진 점

- **원본 확대**: 사진을 누르면 큰 화면으로 열립니다. 두 손가락 확대, 두 번 누르기, 끌어서 이동을 지원합니다.
  긴 이미지는 너비에 맞춰 열고, 확대할 때 보이는 부분을 원본에서 읽습니다.
- **내용 검색**: ‘글자 읽기’를 누를 필요 없이 앱을 열거나 사진을 추가하면 검색을 자동 준비합니다.
  사진 속 숫자·영문·한글을 입력하면 찾을 수 있습니다. 예: `12900`, `ABC`, `예약`.
  처음에는 준비 시간이 필요하며 앱 프로세스가 종료되면 다음 실행에서 이어 준비합니다.
- **선택 영역 캡처**: 화면 캡처 → 선택 영역 → 7초 안에 원하는 화면 → 네모의 모서리 조절 → 저장.
- **긴 페이지 캡처(시험 기능)**: 화면 캡처 → 긴 페이지 → 7초 안에 페이지 맨 위 → 스크롤되는 부분 선택 →
  직접 반 화면씩 내려서 **화면 추가** → 끝에서 **완료·저장**.
  겹치는 부분을 찾아 한 장의 PNG로 이어 저장합니다. 다른 앱을 자동 스크롤하지 않습니다.
- **쉬운 버튼 안내**: 화면 맨 위에서 두 번 내리기 → 연필/편집 → 모아픽 캡처 버튼을 위로 옮기기로 안내합니다.
- **설치 아이콘**: 홈 화면·앱 목록에 보이는 보라색 사진 카드 아이콘과 테마 아이콘을 적용했습니다.

## 알아둘 점

선택 영역과 긴 캡처는 ‘다른 앱 위에 표시’를 허용해야 합니다. 보안 화면은 캡처되지 않을 수 있습니다.
긴 캡처는 처음에 고정 메뉴·하단 버튼을 빼고 선택하세요. 화면 간 겹침이 없거나 판단이 모호하면
잘못 이어 저장하는 대신 재시도를 안내합니다. 너무 많이 내렸다면 조금 위로 올려 다시 추가하세요.
현재는 40개 화면/총 6천만 픽셀/5분 세션을 한도로 사용합니다. 크기 변경·회전은 피하세요.
글자 검색은 OCR의 인식 결과에 따라 달라질 수 있으며 흐린 글자나 손글씨는 정확하지 않을 수 있습니다.

컴파일·분류/검색/카운트다운/스크롤 연결/긴 PNG 저장 테스트 13개와 정적 검사를 통과했습니다.
실제 휴대폰에서의 확대 제스처·권한·캡처·연결 결과·화면 배치는 아직 검증하지 않았습니다.
Google Play에 공개 출시한 버전이 아닌 설치 테스트용입니다.
