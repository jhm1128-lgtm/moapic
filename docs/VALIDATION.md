# 검증 기록 · 2026-10-21

## 0.2.0 변경과 검증

- 사진 단건/다건 삭제: Android 11+ 일괄 시스템 확인, Android 10 파일별 승인·재시도 구현.
- 알림창 캡처 타일, 선택적 홈 화면 바로가기, 타이틀 사진·메인 전환과 아이콘 적용.
- 카운트다운: 마감 시각을 기준으로 7→1 계산. 알림 갱신과 선택적 오버레이 구현.
- 캡처 전 오버레이를 제거하고 새 ImageReader 표면을 연결해 이전 숫자가 남은 프레임을 버리도록 구현.
- 단위 테스트: 분류 4개 + 카운트다운 2개, 실패 0 / 오류 0.
- Preview Lint: 오류 0, 경고 2 (고정한 Gradle 버전, 카운트다운 한국어 문자열 자원화 안내).
- 설치 파일에 R8 최적화, 네이티브 라이브러리 압축, ARM ABI별 분리를 적용.
- 이전 APK 52,492,895 bytes → ARM64 APK 약 8.1 MB. 최종 정확한 크기는 배포 폴더의 checksums.json에 기록.
- 출시용 서명 대신 기존 테스트 버전과 같은 디버그 키로 서명한 최적화 테스트 APK.
- 글자 읽기는 한국어·영문 번들 모델을 그대로 사용하며 인터넷 권한을 추가하지 않음.
- 타이틀 사진: 내장 ImageGen 생성, WebP 640×960 / 41,490 bytes. 프롬프트는 ASSETS.md 참조.

실제 기기와 에뮬레이터는 연결하지 않았습니다. 삭제 승인/취소·타일·카운트다운 권한·숫자 없는 저장 결과·실제 화면 배치는 실기기에서 검증해야 합니다.

## 0.1.0 이전 검증 기록

## 자동 검증

- Java 17 / Android SDK 36에서 디버그 앱 컴파일 및 APK 생성 성공.
- JUnit: 4개 테스트, 실패 0 / 오류 0.
- Android Lint Debug: 오류 0, 경고 1 (고정한 Gradle 버전보다 새 버전이 있다는 알림).
- APK 서명 검증 성공: APK Signature Scheme v2, 디버그 키 1개.
- APK 16 KB ZIP 정렬 검사 통과.
- 포함된 OCR arm64-v8a / x86_64 네이티브 라이브러리의 ELF LOAD 정렬 16 KB 확인.
- 최종 병합 매니페스트에 INTERNET / ACCESS_NETWORK_STATE / AD_ID 권한 없음.
- Windows 빌드 도우미 스크립트 문법 검사 통과.

- 축소·최적화(R8)를 적용한 Release AAB 생성 성공. 공개 배포용 서명은 아직 구성하지 않았습니다.
