# Google Play 출시 방향

모아픽의 중심 용도는 ‘스크린샷과 저장 이미지를 내용으로 다시 찾는 사진첩’입니다.
광고·로그인 없이 기기 안에서 숫자·영문·한글 검색을 제공하는 현재 흐름을 먼저 검증합니다.
성공이나 다운로드 수를 예측할 근거는 아직 없습니다.

## 출시 전에 확인할 것

1. 실제 삼성/픽셀 등 휴대폰에서 권한, 자동 검색, 원본 확대와 삭제를 검증합니다.
2. 긴 캡처는 시험 기능으로 평가하고, 이어 붙이기 실패·중복·누락이 있는지 확인합니다.
3. 사진 관리가 핵심임을 설명하고 전체 사진 접근 권한을 신고합니다. 갤러리 앱이 흔히 해당하지만 승인을 보장하지 않습니다.
4. 화면 캡처용 포그라운드 서비스 신고, 화면 표시 권한 안내, 개인정보처리방침과 Data safety를 최종 앱 기준으로 준비합니다.
5. 소유자가 관리하는 출시 서명 키, 최종 applicationId, 연락처, 스토어 소개와 실제 기기 화면 이미지를 준비합니다.
6. 최신 target API와 16 KB 네이티브 라이브러리 호환성을 출시 직전에 재확인합니다.

2023-11-13 이후 개설된 개인 개발자 계정은 일반 공개 출시 접근을 신청하기 전에
12명 이상이 14일 연속 참여하는 비공개 테스트 요건이 있습니다. 계정별 적용 상태는 Play Console에서 확인해야 합니다.

- [사진·동영상 접근 정책](https://support.google.com/googleplay/android-developer/answer/14115180)
- [신규 개인 계정 테스트 요건](https://support.google.com/googleplay/android-developer/answer/14151465)
- [화면 캡처 API](https://developer.android.com/media/grow/media-projection)

현재 사용자의 요청은 출시 가능성 검토입니다. 실제 스토어 제출은 진행하지 않았습니다.
