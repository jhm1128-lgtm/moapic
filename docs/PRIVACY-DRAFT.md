# 모아픽 개인정보처리방침 초안

공개 전 운영 주체, 문의 연락처, 시행일을 확정하고 실제 출시 버전과 대조해야 합니다.

모아픽은 스크린샷과 저장 이미지를 찾아 정리하는 사진 관리 앱입니다.

## 기기에서 처리하는 정보

사용자가 허용한 이미지의 파일명, 저장 경로, 저장·수정 시각과 이미지 내용을 처리합니다.
즐겨찾기·태그와 이미지에서 인식한 글자는 앱 전용 저장 공간에 보관합니다.
사진 접근은 기존 이미지를 모으기 위해 사용하며, 전체 접근 또는 선택한 사진 접근을 지원합니다.

## 화면 캡처

화면 캡처를 시작할 때마다 운영체제의 화면 공유 동의를 받습니다.
허용 후 약 7초 뒤 한 장을 기기의 사진 폴더에 저장하고 세션을 종료합니다.
빠른 설정 타일/홈 바로가기는 동의 후 약 1.5초 뒤 저장합니다.
남은 시간은 알림에 표시합니다. 다른 앱 위에서도 카운트다운을 보려는 사용자는
‘다른 앱 위에 표시’ 권한을 선택적으로 허용할 수 있습니다. 이 표시는 캡처 중 잠시 나타나며
저장 전에 제거합니다. 다른 앱의 조작을 읽거나 대신 실행하지 않습니다.
앱은 오디오를 녹음하지 않습니다. 사용자는 시스템 표시 또는 캡처 알림에서 세션을 중단할 수 있습니다.

## 전송과 공유

현재 버전은 인터넷 권한, 계정, 광고, 서버 저장, 이용 분석 기능을 포함하지 않습니다.
글자 인식은 앱에 포함된 모델로 기기에서 수행합니다.
사용자가 ‘공유’를 실행하면 선택한 다른 앱에 이미지 읽기 접근을 전달합니다.
이후 처리는 해당 앱의 정책을 따릅니다.

## 보관과 삭제

앱 설정의 초기화 기능은 태그·즐겨찾기·글자 색인을 삭제합니다.
앱을 삭제하면 앱 전용 정리 정보가 삭제됩니다. 자동 백업은 비활성화되어 있습니다.
공용 사진첩의 기존 원본, 가져온 이미지와 새로 캡처한 이미지는 유지됩니다.
이 파일은 휴대폰 사진첩이나 파일 관리 앱에서 삭제할 수 있습니다.
앱의 사진 삭제 기능을 사용하면 확인을 거쳐 선택한 공용 사진 원본을 영구 삭제할 수 있습니다.
삭제한 사진은 앱에서 복원할 수 없습니다.
사진 접근은 기기 설정에서 언제든지 변경하거나 철회할 수 있습니다.
