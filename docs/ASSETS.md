# 시작 화면 사진

도구: 내장 ImageGen. 새 사진 생성 후 앱용 WebP로 크기 조절·압축했습니다.

앱에서 쓰는 최종 파일: `app/src/main/res/drawable-nodpi/splash_photo.webp`

640×960, 약 41 KB. 글자는 사진에 굽지 않고 네이티브 화면에서 표시합니다.
아이콘은 별도 비트맵 대신 `UiIcon.java`의 Canvas와 캡처용 VectorDrawable을 사용합니다.

## 생성 프롬프트

Create a polished photographic brand splash image for a Korean Android screenshot and downloaded-image organizer named Moapic. Portrait 2:3 composition. Soft lavender background (#F8F7FC), warm sunlight, a beautiful understated flat lay of a few small blank rounded photographic cards showing a tranquil sea, a soft sunset and a plant, arranged like a neatly gathered personal image collection. A small lavender binder clip and translucent glass detail. Modern editorial product photography, premium but friendly, calm lavender and cream palette with subtle peach highlights. Main objects in central middle third, generous clean lavender negative space at top and bottom for native app title and slogan to be added later. This is actual photographic art for the splash screen, not a phone mockup or screenshot. No text, letters, watermark, logos, UI, or phone device. Smooth unobtrusive background suitable behind dark purple text.
